模型推导

1飞行：角动量守恒

出手后只受重力，重力对质心不产生力矩，所以关于质心的角动量守恒；质心做抛体运动。

L = I(t)·ω(t) = I₀ω₀  ⇒  ω(t) = I₀ω₀ / I(t)

瓶子总转角 θ = ∫ω dt，要在落地时接近 2π。

2水的再分布

在随瓶转动的参考系里，水受离心力 mω²r，被推向远离质心的两端。用再分布程度 s 描述：一部分水 s/2 移到瓶口端，其余留在瓶底。

ds/dt = (smax − s)·ω² / C
I(s) = Σ [ Ii + mi(zi − zc)² ]

满瓶时水无处可去，I 不变；空瓶时水太少，I 也几乎不变。只有中间水位能让 I 涨到 3–5 倍。

3着地：关于支点的角动量

瓶底一角 P 先触地，冲击力过 P，因此关于 P 的角动量守恒。水段撞到瓶底时，自身动量大多在内部耗散，只按比例 κ 传给瓶体。

LP = Σ [ Iiω + mi ri×vi ]，  ωP = LP / IP

4摇摆与倾倒

水塌回瓶底后，瓶子绕底角做摇摆（Housner 模型）。质心高 hc，半宽 R，临界角 α = arctan(R/hc)：倾角超过 α 就倒。

IP φ̈ = Mgd sin(φ − α)
ω⁺/ω⁻ = (1 − 2MR²/IP)·η水

水位低，质心也低，α 更大，所以落地更宽容。

简化说明：瓶子按 2D 刚体处理，水用两段液柱近似，没有解 Navier–Stokes。C、smax、κ、η 是调出来的唯象参数，目的是复现实验趋势（参考 Dekker et al., Am. J. Phys. 86, 733 (2018) 对水瓶翻转的分析；Housner, BSSA 1963 的摇摆块模型）。瓶子参数：高 20 cm、半径 3 cm、空瓶 25 g。
